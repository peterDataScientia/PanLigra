# PanLigra v1.0.2 — Embedded Windows Desktop

This update replaces the external-browser launch experience with an embedded native Windows desktop window.

## Changes

- Opens a PanLigra-branded application window using Windows WebView2, without launching a separate Edge or Chrome browser.
- Eliminates the visible Command Prompt.
- Runs the local Streamlit application in a hidden, managed subprocess and closes it when the desktop window closes.
- Checks both the local server health and Streamlit homepage before displaying the window.
- Selects another free localhost port if an older PanLigra installation is already using the preferred port.
- Saves startup diagnostics to `%LOCALAPPDATA%\PanLigra\panligra-desktop.log`; displays a Windows error dialog if startup fails.
- Preserves the PLIP scientific analysis, RDKit/Open Babel support, 2D editor, and export features.

## Installation

Download `PanLigra-Setup.exe` and run it on Windows. You do not need Python, Conda, or a separately launched browser.

**Windows requirement:** Microsoft Edge WebView2 Runtime must be present. This is a Windows embedded web rendering runtime, not an external browser window. Existing installations usually already have it.

## Automated validation

Release CI requires PyInstaller compilation, scientific dependency imports, renderer tests, Streamlit server and homepage validation, GUI executable subsystem verification, a visible embedded-window smoke test, and successful NSIS installer packaging.

Automated tests are not a substitute for manual installation and complete PLIP/export testing on the end-user PC.
